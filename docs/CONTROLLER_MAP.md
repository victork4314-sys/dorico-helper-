# Default Xbox controller map

This document is generated from the built-in `Dorico Pro — Legato style` profile.

## Base layer

- D-pad and left stick: navigate Dorico selection.
- A: Return / activate.
- B: Escape / cancel.
- X: Delete.
- Y: start note input with Shift-N.
- Menu: play or stop.
- View and Guide: show or hide the bridge dashboard.
- Left stick click: undo.
- Right stick click: redo.
- Right stick: spatial Accessibility focus.

## Hold LT

- A: copy.
- B: cut.
- X: paste.
- Y: select all.
- Directional controls continue navigation.

## Hold RT

- B: 16th note.
- X: eighth note.
- A: quarter note.
- Y: half note.
- D-pad Up: whole note.
- D-pad Right: rhythm dot.

## Hold LT + RT

- A: dynamics popover.
- B: ornaments popover.
- X: time signature popover.
- Y: key signature popover.
- D-pad Up: tempo popover.
- D-pad Down: clef popover.
- D-pad Left: playing techniques popover.
- D-pad Right: bars and barlines popover.

## Pointer mode

- Left stick: move pointer.
- Right stick up/down: scroll.
- A: left-click.
- X: right-click.
- B: leave pointer mode.
